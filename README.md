# 酵母实验工作台 · Yeast Workbench

本地离线、纯前端的合成生物学实验工作台，面向酵母底盘优化与菌株构建。

## 功能模块

- **菌株 / 底盘库**：编号、基因型/编辑位点、筛选标记、构建方法、来源、亲本谱系、保藏位置、标签、备注；支持搜索与标签筛选，可关联实验。
- **实验记录 ELN**：标题、日期、关联菌株（多选）、目的、方案、试剂条件、结果、结论复盘、标签；时间线视图。
- **克隆 & 引物工具**：引物自动设计 + Tm/GC 计算（含盐校正近似）、单引物分析（发夹/二聚体启发式警告）、反向互补转换、Gibson 同源臂设计、内切酶位点扫描、测序验证定位、序列统计。

## 技术说明

- 纯静态前端（HTML/CSS/原生 JS），无后端、无联网依赖。
- 数据存于浏览器本地 IndexedDB，可在「数据备份」页导出/导入 JSON。
- `sw.js` 提供离线缓存，安装为 PWA（添加到主屏幕）后可离线使用。
- 序列算法（`js/seqcore.js`）为教学/设计级近似，正式下单前请用 NEB 等官方工具复核。

## 本地运行

```bash
cd yeast-workbench
node serve.js
# 浏览器打开 http://localhost:8000
```

## 隐私

所有实验数据仅存于你自己的浏览器/设备本地，不会上传任何服务器。
